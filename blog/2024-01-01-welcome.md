### 🎯 Key Features

Moco brings powerful workflow orchestration capabilities:

- **Declarative YAML Syntax**: Define workflows without writing procedural code
- **Dual Runtime Support**: Develop with in-memory runtime, deploy to Temporal.io
- **Python Expressions**: Leverage Python's power for dynamic behavior
- **Event-Driven State Machines**: Build complex, reactive workflows
- **Pluggable Activities**: Extend with custom functionality
